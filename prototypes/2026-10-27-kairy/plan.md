# 카이어리 (가제) — 차로 기록하는 나의 역사

## 1. 배경
- **계기**: 장거리 운전을 하다 보니 혼자 차 안에 있는 시간이 하루 중 거의 유일하게 방해받지 않는 시간이라는 걸 알게 됐다. 그런데 이 시간이 대부분 그냥 흘러가 버린다. (출처: 본인 경험)
- **가제**: 카이어리 (Car + Diary)
- **지금 차량에서는**: 엠비언트 라이트는 수동으로 고르거나 주행 모드에 따라 자동으로 바뀌는 정도다. 대화나 감정과 연결되는 기능은 없고, 운전 중에 기록할 수단도 없다. 「추정」: 기본 음성 비서는 명령을 수행할 뿐 먼저 질문하거나 기록을 남기지 않는다.

## 2. 문제 정의
- **누가**: 혼자 출퇴근하는 운전자
- **어떤 상황에서**: 출발 전 정차 상태에서 테마를 고르고, 주행 중에는 음성으로만 대화한다. 매일 반복되는 20~60분 구간이다.
- **무엇이 막히나**: 그 시간에 떠오른 감정과 그날 있었던 일이 **기록되지 않고 사라진다.** 운전 중에는 손과 눈을 쓸 수 없고, 혼자서는 무슨 말부터 꺼낼지 막막하다.
- **해결 방향**: AI 질문과 엠비언트 조명은 기록을 잘 끌어내기 위한 수단이다.
- **근거**: 「가설」. 본인 경험 1건이다.

## 3. 범위
### In
- 주행 중 대화 화면: AI 질문, 듣는 중/말하는 중 상태, 현재 조명 색을 표시한다. ← 이번 발산 대상
- 테마나 대화 단계에 따라 엠비언트 라이트 색과 밝기를 바꾼다(실제 SDK 호출).

### Out
- 실제 음성 인식과 AI 질문 생성. 미리 짠 질문 시나리오와 가짜 응답으로 대신한다.
- 테마 선택 화면과 기록 열람 화면. 이번에는 발산하지 않는다.
- 기록 저장, 동기화, 휴대폰 연동
- 주행 중 터치 조작에 의존하는 기능

## 4. User Stories & AC
```
US-1: 주행 중 AI 질문에 답하며 기록한다
  As 혼자 출퇴근하는 운전자, I want AI가 테마에 맞는 질문을 하나씩 던져 주기를,
  so that 무슨 말부터 할지 고민하지 않고 그날의 일과 감정을 말로 남길 수 있다
  AC:
    - Given 테마를 고르고 출발했을 때, When 대화가 시작되면, Then 화면에 질문 1개가 큰 글자로 뜨고 음성으로도 읽힌다
    - Given 질문이 끝났을 때, When 운전자가 말하면, Then 화면이 '듣는 중' 상태로 바뀌고, 말을 마치면 다음 질문으로 넘어간다
    - Given 운전자가 10초 동안 답하지 않을 때, Then 재촉하지 않고 "괜찮아요, 나중에 이어가요"라며 대기 상태로 둔다
    - Given 주행 중일 때, Then 화면에서 읽어야 할 텍스트는 질문 1줄과 상태 1개로 제한한다

US-2: 대화 흐름에 맞춰 조명이 바뀐다
  As 운전자, I want 테마와 대화 단계(질문·듣기·마무리)에 따라 엠비언트 조명이 바뀌기를,
  so that 화면을 보지 않고도 지금 어떤 단계인지 알고 분위기에 몰입할 수 있다
  AC:
    - Given 테마가 '하루 회고'일 때, When 대화가 시작되면, Then 그 테마의 색으로 조명이 바뀐다
    - Given '듣는 중'일 때, Then 밝기가 바뀌어 단계를 알려 준다
    - Given SDK 호출이 실패할 때(onFailed), Then 대화는 계속되고 화면에 '조명 제어 불가' 작은 표시만 남는다
    - Given 대화가 끝났을 때, Then 조명을 출발 전 값으로 되돌린다

US-3: 대화를 마치면 오늘의 기록 한 줄이 남는다
  As 운전자, I want 도착하거나 대화를 마치면 오늘 기록의 요약이 남기를,
  so that 그 시간이 사라지지 않았다는 걸 확인할 수 있다
  AC:
    - Given 기어가 P로 바뀔 때(정차), Then 요약 카드(날짜, 테마, 한 줄 요약, 감정 색)를 보여 준다
```

## 5. 사용할 차량 데이터
| 용도 | API (Vehicle SDK 2.3.2, javap 확인) | 권한 | 실/가짜 |
|---|---|---|---|
| 조명 색 | `getLight().get/setAmbientLightBrightnessColor(SeatArea, Int, …)` | `CAR_LIGHTS`, `CONTROL_CAR_LIGHTS` | 실 |
| 조명 밝기 | `getLight().get/setAmbientLightBrightness(SeatArea, Int, …)` | 〃 | 실 |
| 조명 지원 범위 | `checkAmbientLightBrightness(Color)Capabilities` | 〃 | 실 |
| 정차 감지 | `getGear().getCurrentGearSelectionState` / `registerGearSelection` → `VehicleGear.GEAR_PARK` | `CAR_DRIVE`(추정) | 실 |
| AI 질문·음성 인식·요약 | — (SDK 밖) | — | **가짜** (상수 시나리오) |

- 시안 단계(R1)에서는 화면 레이아웃 비교가 목적이라 조명 색을 상수로 둔다. SDK 호출은 확정안 승격 때 붙인다.

## 6. 핵심 사용자 가치
- 말만 하면 하루가 기록된다. 무엇을 말할지는 AI 질문이 대신 정해 준다.
- 조명이 지금 단계를 알려 주니 화면을 볼 필요가 없다.

## 7. 인터랙션 흐름
1. (정차) 테마 선택: 하루 회고 / 감사 / 내일 계획 / 자유 → 조명이 테마 색으로 바뀐다
2. (주행) AI가 질문을 읽어 준다 → 화면은 '말하는 중'
3. 운전자가 답한다 → '듣는 중', 조명 밝기 변화
4. 다음 질문 → 2~3 반복. 무응답이면 대기
5. (기어 P) 마무리 → 요약 카드, 조명을 원래대로 되돌린다

## 8. 디자인 결정 사항
- 주행 중 화면: 큰 글자, 정보 최소화, 터치 조작 필수 아님
- 앱 영역은 약 1682×1210 (오른쪽 패널)
- 어두운 배경. 실내 조명과 어우러지고 야간 눈부심을 줄인다
