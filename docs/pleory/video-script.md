# Pleory 시연 영상 대본 (제품 필름 16:9)

- 길이: 약 88초. 공모전 규정은 1~2분이다.
- 형식: 1920×1080, 30fps, Remotion 으로 편집한다. 소스는 에뮬레이터 녹화이고, 앱 영역 1682×1210 을 잘라 쓴다(`apk/video/pleory-demo-app.mp4` 와 같은 방식).
- 톤: 검은 화면에 짧은 문장 한 줄로 연다. 화면을 천천히 확대하거나 옮기고 자막을 크게 쓴다. 내레이션은 넣지 않는다. 들리는 사람 목소리는 운전자 혼잣말뿐이다.
- 오디오는 세 갈래다.
  - 운전자 대사: 새 TTS 로 만들고 영상에서만 쓴다.
  - 앱 소리: "적어뒀어"와 요약. 녹화에 담긴 Pleos TTS 를 그대로 쓴다.
  - BGM: 피아노나 앰비언트 한 곡을 −24 LUFS 근처로 깔고, 앱 TTS 가 나올 때는 −8dB 더 줄인다.
- 근거 US: `user-stories.md`. 앱이 실제로 하는 것만 보여준다. P1 기능(QR, 이번 주, 편집)과 Gleo 는 넣지 않는다.

## 녹화와 대사의 관계

에뮬레이터에는 사람 목소리를 넣을 마이크가 없다. 그래서 녹화는 `tools/run-demo.sh 30 text` 로 하고, 앱이 받는 인식 결과 텍스트는 `DemoScenario.kt:31` 의 `TEXTS` 를 그대로 쓴다. 영상의 운전자 목소리는 편집할 때 그 시점에 얹는다.

카드 항목과 요약은 받은 텍스트에서 나온다. 대사의 말(단어)이 `TEXTS` 와 다르면 화면과 소리가 어긋난다. 그래서 대사는 아래 규칙을 따른다.

- 단어는 `TEXTS` 와 똑같이 한다. 한숨·웃음·쉼 같은 소리 표지만 더한다. 표지는 TTS 감정 태그로 넣는다(`[sigh]`, `[exhales]`, `[pause]`, `[soft laugh]` 자리 표시. 실제 태그 문법은 고른 TTS 에 맞춘다).
- 기본안(A)은 run-demo 의 발화를 바꾸지 않는다.
- 대안(B)은 "아 맞다" 같은 군말을 넣는다. 더 사람 같지만 `DemoScenario.kt:31` 과 `DebugPanelActivity.kt:144` 의 `TEXTS` 를 함께 바꿔야 한다. 그 뒤 카드 항목 문장과 요약("노을로 끝났어")이 그대로 나오는지 다시 녹화해 확인해야 한다. `tools/run-demo.sh` 파일 자체에는 발화가 없다.

| | 앱이 받는 텍스트 (`TEXTS`) | 대사 A (기본, 코드 변경 없음) | 대사 B (선택, `TEXTS` 변경 필요) |
|---|---|---|---|
| 1 | 오늘 팀장 때문에 진짜 힘들었다 | `[sigh]` 오늘 팀장 때문에 `[pause]` 진짜 힘들었다 | `[sigh]` 아… 오늘 팀장 때문에 진짜 힘들었다 |
| 2 | 내일 거래처 서류 다시 보내야 해 아 노을 예쁘다 | 내일 거래처 서류 다시 보내야 해 `[pause]` `[soft laugh]` 아 노을 예쁘다 | 아 맞다, 내일 거래처 서류 다시 보내야 해. `[pause]` 어, 노을 예쁘다 |

B 의 2번은 "아"가 "어"로 바뀌어 원문 항목 문구가 달라진다. B 를 고르면 카드 컷의 자막도 새 문구로 맞춘다.

## 자막 원칙

- 화면 하단 중앙, 흰 글자에 그림자만 준다. 상자 배경은 쓰지 않는다. 글자 크기는 1080p 기준 52px 이상.
- 한 컷에 한 줄. 운전자 대사 자막만 두 줄까지 쓴다. 대사 자막은 따옴표 없이 회색(#C8C8C8)으로 써서 설명 자막과 구분한다.
- 시각 칩(18:57 등)은 좌하단에 작게 둔다. 녹화 속 앱 시계와 같은 시각이어야 한다.
- 장소 자막은 화면에 실제로 찍힌 라벨만 쓴다. 지금 경로에서 19:08 라벨은 "올림픽대로"다. "한강대교"는 좌표 표가 반영된 뒤에만 쓴다.

## 녹화 체크리스트

1. 다른 경로 재생이나 에이전트가 에뮬레이터를 쓰고 있지 않은지 확인한다. 겹치면 거리가 48km 처럼 나온다.
2. 앱을 force-stop 했다가 다시 켜고 3초 기다린다. Claude 연결을 미리 열어 두는 시간이다.
3. `adb emu screenrecord start --time-limit 180 <절대경로>.webm` 를 실행하고 바로 `tools/run-demo.sh 30 text` 를 돌린다.
4. 요약이 끝나고 4초 뒤에 녹화를 멈춘다. logcat `PleoryFlow` 에서 두 번 모두 `llm ok: claude` 인지 확인한다(RAW 이면 카드가 달라진다).
5. 18번 삭제 컷은 같은 테이크 끝에 이어서 찍거나 따로 찍는다.
